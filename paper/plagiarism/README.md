## 四、注意

1. **作者信息不一致**：两份报告的文档名与作者栏取自上传时的版本（当时为单作者
   "丁锐"），而论文最终版为四位作者。技术内容一致，不影响检测结论。
2. **外文库局限**：大雅对 IEEE、ACM 会议论文集的收录有限，其查重读数偏低不能完全
   等同于 Turnitin / iThenticate。但本文核心内容（实测数据、负结果结论）为本仓库
   实际产出，原创性有实证支撑。
3. **大雅不区分人机协作**：AIGC 检测基于文本统计特征，无法识别"人写内容 + AI 润色"
   与"纯 AI 生成"的区别。本文的论点、实验与代码分析均来自实际工作。
